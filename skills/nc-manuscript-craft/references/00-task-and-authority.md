# 00 任务、作者决定与证据底稿

## 用途

本模块把作者决定、研究证据和多轮建议整理为当前可执行的写作任务，并按写作模式确定输入。

| 写作模式 | 必需的工作基础 |
|---|---|
| 从零起草 | 作者的口述稿、思路或科学问题，以及可用项目材料；可据此逐步形成完整正文 |
| 润色、局部修改或重构 | 当前正文或目标段落，以及理解和修改所需的上下文；以它们为编辑基线，保留已有科学内容和作者表达 |

已有稿件的任务先读取现稿，再判断需要哪些项目来源。输入齐备后直接推进已授权工作。

## 1. 将输入分成四层

| 层 | 包含什么 | 如何使用 |
|---|---|---|
| 当前作者决定 | 最新请求、明确回答、手改稿、已同意的范围变更 | 决定本轮编辑范围、表达意图、交付形式 |
| 当前科学底稿 | 最终数据/结果、方法定义、图表、参考库和已确认状态 | 决定能写什么，不能由风格要求改变 |
| 历史建议 | 外部评阅、此前助手提议、尚未实施的计划 | 用作候选，不自动写入成稿或恢复旧阻塞 |
| 范例与教程 | 粘贴长prompt、NC论文写法、GitHub技能示例 | 学习写作动作，不借用其数据、经历、机制和强动词 |

作者写“参考这些方法，判断哪些可用”，意味着需要筛选，不是照单执行。作者认可稿件达到成熟状态后又要求少量微调，也不意味着授权推倒全部结构。

当作者提供科学状态更新，记录为“作者已确认的当前前提”。如本轮只做写作，不凭旧审计反复宣称该任务尚未完成。也不把作者确认的存在性外推为未提供的精确版本、许可或数值。

### 外部意见先与当前稿定位

收到评阅时，先确认其针对的版本、段落或图表，再判断属于事实或语义问题、表达改善、格式问题，还是当前稿已经满足的建议。采纳能解决阅读问题的目的，具体改法仍须与本稿证据相符。

若意见中的错字、重复或编号在当前文本中找不到，按需要对照原生文件文字、实际页面和导出文本，区分内容、字形与转换造成的差异。格式故障应修在产生故障的层，再同步相关输出。审阅说明中引用了某个错误词串，不等于稿件中仍存在该错误。

编辑记录分别写明“已修复”“原文已正确”“本次版本未复现”或“尚待定位”，附足以复查的位置。未确定原因时保留这一状态，不把猜测写成纠错事实。此核查用于裁决具体争议，不要求普通句级编辑逐次进行全文件取证。

## 2. 处理时序覆盖

维护一个简短的决定表：旧要求、后续决定、覆盖范围、仍保留部分。以下为教学情境，不代表任何实际项目的经历：

- 原先只改红字，随后允许整个Discussion重写：扩大Discussion范围，不扩大其余黑字范围。
- 原先使用矢量图嵌入文档，后来为某一阅读器的兼容性选择位图：只在指定文档中替换显示资产，可编辑源仍保留。
- 原先图注采用固定次序，后来要求少量变化：取消机械同序，保留读图信息要素。
- 原先只要求图集，后来明确按完整Figure阅读：默认一张完整Figure一页，包含所有panel。若作者或目标期刊另有要求，依当前配置编排并保留完整组图身份。

最新决定只覆盖它明确涉及的事项。不要用一句“继续优化”消除全部保护条件，也不要拿旧范围锁阻止作者已经授权的新工作。

## 3. 最小证据任务卡

对于要写入论文的关键结果，记录以下内容。小段编辑可以在内部完成，不强制让作者填表。

1. **对象**：研究对象、观测或实验单位、变量、指标及输出。
2. **任务**：描述、比较、解释、检验、预测或应用。
3. **范围与条件**：来源、纳入资格、观察时段、处理条件和筛选过程。
4. **估计量与比较**：测了什么、按哪个单位、相对什么比较、方向如何定义。
5. **结果**：真实数值、区间、检验与图表定位。
6. **证据作用**：直接观察、计算推断、实验或其他证据各自支持什么判断。
7. **作者选择**：已有设计或分析选择的目的，以及相应材料依据。
8. **后续问题**：实际观察留下的待解释问题，按论证需要说明。

存在两个同名文件、两组数字或两版术语时，先追到被当前稿引用的来源。不能依照哪个数字更阳性或哪个句子更顺来裁决。

## 4. 按任务选择修改深度

**架构规划**需要查看全篇结果、主要图和中心贡献。先给证据关系，再决定章节。材料不足时给路线和缺口，不把计划写成结果。

**章节起草**需要足以支持该节的结果和文献。用户明确请求起草且材料充分，可以直接完成，不必以某篇教学文“先出框架”为由停在提纲。

**成熟稿修订**保留已有效段落，逐项修复具体问题。区分必须修复与可选改善，按具体收益决定KEEP或修改。问题解决后核查受影响接口并交付，不为同义替换再次打开已完成章节。

**只读审查**输出可定位问题与建议，不覆盖文件。**文件编辑**使用明确的当前基线，保留原件或按用户约定原位修改并备份。

## 5. 明确可以自主处理与需要事实确认的差别

标点、局部语法、避免重复、句长调整、按已知格式同步等通常属于已授权编辑，可直接完成。缺少图注中的样本单位、两版效应相互矛盾、把关联提升为因果或判断某机制是否真实，则需要来源或作者决策。

QUERY用于标记影响含义的未知。它不应扩展成每个词都要用户批准，也不能在独立工作尚未完成时提前停工。先交付已可完成内容，清楚写出剩余问题及其影响。

## 6. 保持源材料、编辑说明和稿件各自的用途

稿件直接呈现研究对象、实际工作、结果与意义，理解这些内容所需的条件写在相应位置。作者说明记录编辑取舍和待补事实，工作记录保存来源、历史操作与检查结果。三类材料各自承担明确用途。

### P00-A 任务定界 prompt

```text
请先根据以下当前稿件、作者修改与本轮要求，确定执行范围，然后直接完成已授权的部分。
输出一个简短任务卡：当前基线、中心问题、可改部分、保护内容、后续覆盖旧决定的范围、需要来源确认的科学问题。
区分作者直接指令、粘贴参考、助手建议和已实施结果。不要把参考示例中的事实写进正文。
外部意见先定位到当前版本。若引述文字与原件不符，核对原生内容、实际显示和导出层，再决定修复位置与状态。
成熟稿以最小必要修改为原则。信息已经充分时不要重复提问或只交计划。
【当前稿件与版本】
【本轮要求及作者手改】
【相关结果、图表、文献】
```

### P00-B 历史冲突合并 prompt

```text
请合并以下多轮写作决定，形成当前有效规则表。
每条记录原要求、后续决定、覆盖范围、当前处理和来源位置。
把通用规则、作者偏好、项目事实、历史已撤回意见分开。
新决定只覆盖其授权范围。已完成的科学前提不要因旧审稿意见重新变成阻塞。
用清楚的正面定义呈现贡献和条件，保留统计范围、必要事实及原有结论强度。
【历史决定】
【最新作者决定】
```
