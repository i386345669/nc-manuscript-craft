# 08｜补充材料：与主文同步的科学写作

> 应用范围：按本轮授权、请求语言和目标期刊配置执行。下文涉及双语、文件或图形交付的步骤，仅在任务需要时启用。教学示例不构成新项目事实。

补充材料承载可复现细节、完整结果和读图信息，具有与主文同等的科学与语言标准。它不是运行日志、删句回收站或防御性声明仓库。本模块用于现有SI定向修改，也可据完整来源构建SI。主文以何种权限可改、补充材料以何种权限可改应分别登记，不能因SI获授权就重写主文。

## 输入与覆盖

读取本轮请求处理的SI语言版本、补充图与图注、表格及说明、补充方法、主文相关段落与引用、作者修改副本、精确参数和冻结来源。建立全覆盖索引：每张补图、每张表、每个补充方法小节、正文引用入口及当前文件。不要只扫图注后声称SI全文已修改。

若作者提供带红字/删除线副本，先提取已生效差异、批注和格式语义。红字改写、红字加删除线删除，未标位置按本轮权限保护。作者已删内容不能换到附录重新出现。保留原件，修改另存。涉及双语版本时同步。

## 组织原则

按实际内容分Supplementary Figures、Tables、Methods或期刊要求的其他部分。标题说明对象和任务，正文直接进入方法、结果和定义。不要在每节开头解释“本节不能证实什么”。读者需要知道做了什么、怎样做、看到了什么以及怎样读图。

每段先识别功能：

| 功能 | 处理 |
|---|---|
| 参数、资格、分母、变换、区间、统计家族 | 保留并使定义清楚，必要时表格化 |
| 补充结果与完整比较 | 如实写方向/量级/不确定性，不做正向包装 |
| 图表编码及误差定义 | 放图注或表注对应位置，避免读者跨多处找含义 |
| 为预判审稿质疑重复说“不证明/不认证/不能泛化” | 删除修辞层，把必要身份融入量或设计名称 |
| 旧回执、debug历史、修稿原因、已修正错误 | 移至audit/溯源记录，SI只保当前复现信息 |
| 正文已有定义且SI没有新用途 | 合并或准确交叉引用，避免重复长段 |
| 操作本身的否定，如未重新拟合 | 按实际科学意义保留或改成固定权重的肯定定义 |

不能靠机械禁词删除所有“未”“不”。“未达到阈值”“未测得有限值”可能是结果或规则。也不能把“不显著”换成“趋势明显”来制造阳性叙述。

## 从范例学习而非复制模板

先读提供范例的完整图注、表和方法，再记录每部分目的、信息密度及省略的理由。范例图中已自明的流程可以用短图注，实验/模拟并列的图则必须写单位、n、线条身份和检验。完整不要求每条图注等长。

范例的页数、图数和表数只适用于它的证据负担，不构成新稿配额。发表过的文件也可能有交叉引用或分页问题，仍应独立检查。期刊正式格式要求另行查核，不能从某篇范例没有Supplementary Methods推断当前稿也不能有。

## 正面定义如何代替防御性叙述

以下为教学合成例，只用于说明编辑动作，不报告任何实际项目结果。

原句：“这些重复并不是独立队列验证，因此不能据此推断外部泛化。”
合适做法：在该图的首次定义处写“各次运行使用相同观测对象并重复执行既定流程”，后文按重复计算报告结果。若外部泛化是讨论重点，在相关论点位置集中说明证据范围，无须各处重贴。

原句：“此处的置信区间不是全流程可靠性证明。”
应查实际计算后写“区间为对保存的患者级预测进行配对重抽样得到的百分位范围”。若来源就是有效抽样百分位，则准确保留名称，不擅自改为全流程置信区间。

原句：“这些输出不认证不同引擎结果可以混用。”
应定义每个数值产品的输入、变换、版本与用途，保持源表对应。对于作者已删去的重复修辞，使用现有准确定义保持范围，不重新添加整段自辩。

## 主文、SI与独立表册同步

正文简化的工程参数必须在SI保留精确值和来源，改写范围只限明确授权值。效应量、阈值、统计结果不能顺手round。SI公式保留原生结构及上下标，独立表册与SI内表在数字、题注和脚注上一致。

主文与SI若独立编号参考文献，应分别维护，不把总RIS库项数当正文引用数。补图移动或拆平后，更新中英正文、图注、表注、图源MD和导航，反向检查所有新编号有去处。术语、固定评分组成、比较组和统计名称保持一致。

少用非必要分号，但技术字段分隔及复杂分组可保留。改变句界后再查引文和条件覆盖，避免多一处句号造成后半句失去范围。

完整Figure合集默认一图一页，用户或期刊另有明确要求时采用相应分页。任何方案都不能以未组装的单panel分页版充当完整补图阅读版。独立面板仍保留编辑用途。SI文字文件和图合集分别验证完整性。

## 验收与停止条件

要求全部索引项有对应输出，作者删除请求落实，未授权内容未改，数字/公式/表结构/来源保护通过，要求双语时主张和条件对齐，图表引用正确。真正渲染全部输出页面，检查近空页、表头、跨页表、裁切、字形、公式和图号。

检测到问题则定点修复并重查受影响内容，无新问题后停止。不可因“还想更像人写的”反复全稿改写，也不提供未测得的AI检测改善百分比。无法核定的科学问题单列并完成其余工作，不以旧已解决问题反复阻塞。

## P08-A｜SI完整覆盖与结构诊断

请完整读取本轮请求语言的补充材料、图表、方法、作者副本及相关主文，先列覆盖索引。逐段标记是复现定义、补充结果、读图说明、重复内容还是审计/防御叙述。保留必要数据、统计与真实结果，把元叙述从论文中剥离。作者删除内容不得转移恢复，未授权主文不改。输出结构问题、最小修复、主文/表册/图注同步点及实际未读范围。输入与权限：【粘贴】。

## P08-B｜SI去防御而不改科学含义

请按已确认覆盖索引修订SI，直接交代对象、操作、观察和读图定义。删反复“不能说明/不是验证/不认证”的自辩，把载重范围写进准确设计或量名称。保留操作性否定、真实阴性结果、数值、资格、分母、区间性质、统计家族、公式与来源。工程参数若获准正文近似，SI仍保精确值。少用分号，不机械替换技术分隔符。按请求语言输出完整改稿及原文—改文—理由—语义核验表。双语任务同步两版。材料：【粘贴】。

## P08-C｜SI与主文、补图、表册的终检

请独立比对修改前后SI与主文、独立表册、完整补图合集。检查遗漏、越权改动、已删内容回流、图号、引用、人群、测量身份、统计定义、双语条件和精确参数。检查接受真实修订得到清稿、拒绝修订回到指定基线，原生公式保持。逐页看渲染结果，验证补图合集按当前分页要求保留完整Figure与全部panel。未另指定时采用一Figure一页。区分核查通过、已修复、未能核查，不写笼统全通过。无新实质问题即停止。输入：【粘贴】。
