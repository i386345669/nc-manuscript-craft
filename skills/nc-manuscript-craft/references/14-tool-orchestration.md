# 14 写作工具的职责与组合

> 应用范围：按本轮授权、请求语言和目标期刊配置执行。下文涉及双语、文件或图形交付的步骤，仅在任务需要时启用。教学示例不构成新项目事实。

## 为什么需要这一模块

不同技能是指令库，并非天然独立的专用模型。选择工具要依据本轮任务和可观察收益，不以工具数量或串行改写次数作为质量指标。下面讨论职责分配，不提供工具普遍优劣排名。

本skill已包含执行所需原则。以下工具可在可用且任务确实需要时帮助工作，不是强制依赖，不要为普通编辑自动安装全部工具。

## 1. 各工具最适合承担什么

| 来源/技能 | 可采用能力 | 需要限制的地方 |
|---|---|---|
| Evidence-Bound | 贡献与范围契约，判断防御修辞的实际作用，集中修订后语义回归 | 不能把其诊断流程变成每次修改都要重新批准。其他学科项目的专属规则不迁入本文 |
| Academic Humanizer | 拆分复杂句，明确对象，保护学术限定、术语和作者判断 | 不是“所有长句都拆”。不能只验数字就宣布语义安全 |
| Humanizer | 末轮寻找重复收束、空泛评价、假对比、模板开场 | 不据词表批量删why-next、we或必要限定。建议逐项采纳 |
| Leey 写作提示集合 | 指定段落翻译、精简、结果描述、图表题目、逻辑检查 | 上游部分模板偏CS会议。目标语域、时态、科学证据与当前任务优先。Word纯文本不是DOCX |
| Academic Research Suite | 研究问题、论证架构、claim–evidence审查和有范围的模拟评阅 | 成熟稿不用重启选题、实验或整套研究流水线。语言编辑不授权新分析 |
| Nature writing/polishing相关技能 | 章节职能、问题与证据、读者路径、范文结构学习 | 本地期刊限额可能过时。发表范文的措辞不能替代本稿证据 |
| 文档/PDF/科研图工具 | 实际生成文件、真修订、公式和版面核验 | 文本检查不能代替看页面，文件存在也不等于显示正确 |

## 2. 根据成熟度安排步骤

**材料零散时**：先证据与中心问题，再框架、图证组织、正文。语言工具放在实质论证之后。

**已有成熟稿时**：固定现有底稿和作者决定 → 找需要局部结构修复的段落 → 学术清晰度精修 → 按请求同步语言版本 → 少量去模板建议 → 独立语义与图文回归。

**只改分号或图注时**：读取受影响段落及必要上下文，逐项改写并同步副本。无需依次运行全部技能。

**比较两种写法时**：从同一基线各自生成候选，保留原始输出和差异。不要先修好某工具的输出再拿去与另一工具原始输出比赛。

## 3. 用教学合成例检查候选风险

以下例子为教学构造，不是对任何工具的实测评价。

**桥接丢失。** 候选稿删除了解释为何采用共同纳入规则的句子，文本更短，但读者不能理解后续比较。应恢复必要设计理由，不以字数最少判优。

**条件扩大。** 原文为“仅对未完成问卷的记录补发提醒”，候选变成“对全部记录补发提醒”。数字和引文可以完全相同，适用集合却改变。应回看条件作用域。

**修饰关系漂移。** 原文中只有一项指标按权重汇总，合句后看似所有指标都加权。应将限定紧邻被修饰的量，并对照定义，不能凭读起来顺就认定正确。

## 4. 选择和采纳工具建议

每个候选改动检查四点：它修复了什么具体问题，是否保留段落任务，是否保留科学与引文范围，是否增加新的同步工作。若收益只是“更像某工具习惯”，保留原句通常更稳。

对有分歧的候选，写出取舍依据。保留一份推荐稿，必要时提供一个有明确不同用途的备选。不要将没有实际差异的五个版本交给作者选择。

## 5. 评价与独立复核

独立模拟评阅可以评语言、逻辑、叙事、可读性和具体证据风险。记录使用同一模型还是不同模型、是否隔离上下文、是否匿名、材料是否相同。评阅报告在综合前冻结。

主观打分、真实检测器输出、期刊接收概率是三种不同信息。没有运行检测器就不报生成率。模拟编辑评分不是实际编辑意见，也不保证投稿结果。

当用户要求“直到满意/投稿标准”，按明确问题迭代并保留修复记录，不要求评审者必须给好评，不删掉相反意见来制造一致。

## 可复制 prompts

### P14-A 成熟稿工具协作

```text
请基于当前成熟稿做一次有范围的科学编辑，并按请求语言精修。
先固定贡献、对象身份、作者决定和不可改项。仅对实际存在结构问题的段落调整论证。
学术清晰度修订后，若本轮要求双语，同步另一语言。最后只用通用humanizer思路提出局部套话删改，不让多个工具轮流全文重写。
保留原稿、原始候选和最终采用稿的区别。每项采纳说明收益，检查条件、量词、比较对象、引文作用和why-next。
不用模拟分数推算AI生成率或录用概率。完成约定核验后停止。
【基线/本轮目标/材料/输出】
```

### P14-B 同底稿候选比较

```text
请从同一冻结底稿独立生成方案A与B，差别仅为我指定的编辑策略。
保留每个方案第一次成功输出，不先修补其中一方。分别给逐段差异和未改决定。
评价语言、逻辑、衔接、可读性及科学含义，不以更短或改动更多判优。
若需要多位模拟评阅，使用相同匿名材料、独立上下文，先冻结报告再综合。
记录已观察的语义回退并在推荐稿中修复，不篡改原始对照产物。
【底稿/策略A/策略B/评价范围】
```
