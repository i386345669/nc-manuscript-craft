# 10｜从相关原始论文学习写作，而非复制期刊腔

> 应用范围：按本轮授权、请求语言和目标期刊配置执行。下文涉及双语、文件或图形交付的步骤，仅在任务需要时启用。教学示例不构成新项目事实。

本模块用于作者要求“学习这些高水平论文怎样讲故事”时，也可用于检查稿件为何有流水账或过度模板化的问题。学习对象是论证动作和图文关系，不是高级词表，更不是移植已发表论文的证据强度。

## 任务边界与输入

先区分三种任务：找写作范例、为科学陈述补引用、核实期刊当前规则。它们的证据要求不同。文章适合做写作范例，不代表它直接支持本稿某条科学主张。作者提供的旧期刊规则也不能自动当今天的投稿要求。

输入包括本稿类型与成熟度、需要改进的章节、作者指定参考论文，以及可读取的原文。已有成熟稿只需局部语言调整时，不必重新检索整个领域。先使用已经读过并有记录的适当材料，只有存在缺口时再补充。

## 选择文献：相近的推理任务比相近的名词更有用

优先选择原始研究，并解释每篇为什么有参考价值。例如一篇展示从方法评价进入生物学用途，一篇展示全局图谱如何缩小到局部化学，一篇展示多个输入如何引出匹配比较。不要仅按“Nature”“癌症”“代谢”标签堆文献。

通常少数互补范例比大量未细读论文更有用。论文数量随任务确定，不设必须五篇或十篇。作者明确给的范例先读取，若只能访问摘要，就如实限定学习范围，不推断其全文如何组织。

## 阅读与记录步骤

### 1. 建立真实覆盖记录

记录标题、DOI、原始网址、获取日期，以及实际读取的Abstract、Introduction、Results小节、Discussion和图注。区别读取全文、只看某段、只看图注和真正查看图版。文件清点或关键词命中不等于完整阅读。

可保存原始HTML/PDF及可搜索文本，注明提取是否保留图注和表格。不要把旧代理或旧报告记载的全文阅读冒称本轮已读。本轮只回读必要章节也完全可以，只需说明目的和范围。

### 2. 读出每段在做什么

对所选章节记录：段落提出什么问题、报告什么观察、用了什么比较、说明什么原因、如何联系下一部分。不是每段都有这些动作，也不是每个动作都要写成显式句子。

同时看标题与段首是否相互呼应，主语怎样从方法转为生物对象，图在何时引入。将全文压成一条问题关系图或简短顺序表，识别平行用途、反例和分支，不能把所有文章都归纳为同一种线性模板。

### 3. 核对图文分工

看一组图的中心判断，以及各panel如何贡献分布、对照、尺度和解释。区分正文给出的主要结果、图注定义的读法与SI保留的细节。借鉴的是功能分配，不是每图同样的panel数、同样的颜色或同样的统计检验。

例如跨细胞系相关与单细胞系内部相关是不同的评价轴。若范例把两轴分开，值得迁移这种区分。若范例在某处概括过强，不因它已经发表就照搬。

### 4. 做迁移判断，而非摘抄句式

为每项可学做法写三列：原文动作、本稿对应证据、可执行改法。没有本稿对应证据的动作不能迁移成完成式结论。例如参考论文有药物实验，本稿仅有模型删除，能借鉴从网络提出问题的顺序，却不能借用“治疗脆弱性已验证”的说法。

识别范例不值得学的地方，包括反复总括、过度宣传、未经直接比较的优越性和不清楚的统计单位。高水平论文也是具体研究的产物，不是不可批评的写作规范。

### 5. 用本稿段落验证学习是否有效

选择一两段真正需要改变的文本，给出改前、改后与理由。理由应具体到读者理解，例如“先看到共享模式，随后理解去冗余为何必要”，而不是“更像Nature”“更高级”“更有人味”。

检查新文本是否仍由本稿数据支撑，是否增加了不存在的因果、先验假说或新颖性。不追求所有段落统一。一项做法对Introduction有效，不一定适合Methods或图注。

## 公开论文候选：按任务选择核读范围

下列公开原始论文可以作为方法、资源和测量叙事的候选参照，不是必读清单。表中列的是阅读任务，不代表当前执行者已经完成阅读，也不把这些文献自动加入新稿参考表。实际使用时记录读到的章节、图注和图版。

| 公开来源 | 可带着什么问题阅读 | 迁移边界 |
|---|---|---|
| [METAFlux，Huang等，2023](https://www.nature.com/articles/s41467-023-40457-w) | 如何区分benchmark的评价单位，以及怎样从性能比较进入生物学用途。 | 性能数值属于原文，不可变成本稿结果。 |
| [Lewis与Kemp，2021](https://www.nature.com/articles/s41467-021-22989-1) | 多输入为何需要相应架构，同输入比较如何服务论证。 | 依新稿实际设计决定独立性与适用范围。 |
| [Rosario等，2018](https://www.nature.com/articles/s41467-018-07232-8) | 全局分布如何聚焦具体分子过程，以及图组怎样分担观察与干预。 | 原文实验强度不属于借鉴结构的新稿。 |
| [Gaude与Frezza，2016](https://www.nature.com/articles/ncomms13041) | 一个观察如何引出多个有区别的研究问题。 | 不移植原作者的假说历史和验证经历。 |
| [Xiao等，2019](https://www.nature.com/articles/s41467-019-11738-0) | 分辨率差异如何形成结果比较与讨论任务。 | 分辨率能力必须来自新稿自己的输入与方法。 |

学习的目标是问题、证据与图文职责的关系，不是导出“每段必须结论先行”“每节必须why-next”或“每篇必须一个意外发现”的规则。

## 常见失败与修法

| 失败 | 修法 |
|---|---|
| 只摘“novel、robust、comprehensive”等词 | 记录段落和图的职责，用本稿具体对象替换抽象功能句 |
| 只看摘要就声称学习了全文风格 | 限定阅读范围，读取目标章节再做章节级建议 |
| 文献成功所以本稿也用同样强动词 | 比较两者证据设计，按本稿证据决定动词 |
| 把范例的每个步骤当必须补的实验 | 区分叙事学习与研究缺口，成熟稿默认局部修改 |
| 把论文中的假说或意外变成作者经历 | 只有作者日志支持才写过程语句，否则改为当前结果或分析目的 |
| 写作范例同时被当成万能引用 | 每条科学主张另做支持对应，核对原文是否直接支持 |
| 固化旧版NC字数/图数限制 | 使用时查当前官方页面，注明日期，不把历史技能值当常量 |

## 审查点

- 选择每篇文献是否有明确的叙事或图文学习任务。
- 是否记录实际读到的内容，没有夸大覆盖。
- 迁移表是否有本稿证据，不只是原文好句。
- 是否识别了范例不应模仿的表达或统计习惯。
- 是否产生具体局部修订，而非抽象“提高故事性”建议。
- 是否保留章节差异和作者语气，没有换成新的统一模板。
- 文献学习、科学引文和当前期刊规则是否各有其证据路径。

## 可直接复制的 prompts

### P10-A｜选择并细读写作范例

> 我希望改进[章节/问题]，研究类型是[类型]，当前稿件成熟度是[初稿/成熟稿]。请先读取我指定的原始论文，再按需要补充少数结构相关的范例。逐篇说明选择理由和实际阅读范围，区分读全文、读章节、读图注与看过图版。提取其问题推进、段落职责、主语变化、主要比较和图文分工，不制作高级词汇清单。随后把可用做法映射到我的现有证据，说明哪些可以采用、哪些因证据设计不同不能采用。不要移植别人的性能结论、机制强度或研究经历。

### P10-B｜比较范例与当前稿，形成可执行编辑

> 请对照[范例原文的指定章节]与[我的稿件章节]进行结构性比较。先分别用简短顺序表概括两者的段落任务，再找出我稿中重复操作记录、抽象功能句、对象断裂或图文失衡的位置。最多选择[数量]个真正需要改变的段落，给出原句、修订文本、证据来源与改善理由。保留数据、引文、分析对象和结论强度。不要把全部段落改成同一个模板，不因范例发表在高影响期刊就接受其所有措辞。

### P10-C｜建立学习记录与迁移表

> 请将本次论文写作学习保存成可追溯记录。每篇列标题、DOI、原始网址、获取日期、实际读取的章节和图注，以及没有读取的范围。对每条编辑建议列“原文的论证动作—本稿对应证据—拟采用改法—不能借用的结论”。简短引用只用于定位，主要用自己的话解释。写作学习不等于论文的统计复现，若仅有本地旧快照，不要宣称重新核查了当前期刊规则。最后用一段本稿的真实文本展示学习成果。
