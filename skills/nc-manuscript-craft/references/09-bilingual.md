# 09 中英双语：准确传达同一科学论证

双语稿需要在同一事实、同一推论和同一引用关系上可互相核对。英文可以更简练，中文可以为语法自然调整结构，但不能有一版多一个机制、少一个条件，或相同数字指向不同对象。本模块只在任务要求双语或多语对应时使用，检查范围包括段落身份、证据层级和统计含义。

## 一、准备双语对齐基础

初次双语起草可从作者的口述稿与项目材料出发，依据共同证据形成两版。翻译、润色、局部修改或同步已有文本时，当前源文或目标段落及必要上下文是必需基线；已有对应语言稿时一并读取。明确主要编辑版本、术语、数据/统计定义、图表引用及修改范围，两版均有作者改动时先核对并保留其有效内容。

建立稳定段落ID，按科学功能配对，不只按当前Word段落序号。段落发生拆分或合并时保留映射，例如R3-P2对应中文两段与英文一段。图注、Methods、表注和补充材料也纳入，不只核正文。

推荐对齐表：

| 字段 | 内容 |
|---|---|
| 段落ID与职责 | 本段回答什么问题 |
| 中文/英文 | 当前完整文本 |
| 受保护事实 | 数值、方向、对象、条件、终点 |
| 引文与图表 | 每个标记支持哪一句或哪项对象 |
| 允许变化 | 语序、分句、句长、重复压缩 |
| 不允许变化 | 含义、证据强度、分析范围与归属 |

## 二、术语先定，句式可以变化

术语表不仅是中英词对，还应含定义、适用范围、常见误译和不能混淆的邻近概念。观测对象、样本记录、分析单位和统计汇总可对应不同计数，应分别保留准确名称。

同一研究对象保持统一名称。句子不需要统一开头，同一术语也不应为了避免重复被任意换成近义技术词。对modelled/inferred/measured、association/effect、score/readout/assay等词，先保护其证据身份，再考虑语言自然。

首次出现的全称、缩写和后续简称两版可以符合各自语言习惯，但读者能明确对应。必要时在术语表保存缩写允许出现的范围，避免摘要、主文、SI各自发明不同名称。

## 三、数字之外必须核对的七层含义

1. **量词和单位**：分别确认观测、实验、分析和重复计算的单位，使名称与计数对应。
2. **分母与集合**：计划数、纳入数、合格数、成功数、完整病例数是否同一。部分有效病例的结果不能在另一语言里变成全队列结果。
3. **条件与范围**：在何种人群、处理、模型约束、输入、参数与时间窗下成立。“本研究条件下”不能被译丢。
4. **终点与尺度**：明确每项结果的终点、单位、变换和比较尺度，保留不同指标各自的统计含义。
5. **因果与强度**：关联、提示、伴随、支持、证明或导致的语气是否对等。英文精简不等于增强结论，中文解释性表达也不能添因果。
6. **否定与例外**：not、only、except、no、remaining及中文“仅”“未”“除外”“仍”的作用域。少一个限定可能改变整段意思。
7. **引用归属**：括号图号、文献和补充表究竟支持前一句哪项主张。标记数量一致也不代表位置正确。

逐项检查后再做数值比对。数值token一致只是辅助证据，不能替代语义审核。教学情境：某表号从“训练集描述”移到“外部评价结果”句后，即使编号和数字都保留，也可能指向错误对象。因此需检查引用标记的实际职责。

## 四、数字、统计与公式的处理

精确数值与舍入按已确认方案进行。若正文采用近似表达，双语都保持同样精度与“约”的含义，SI中的精确参数不因正文润色改变。统计符号、负号、指数、百分数、区间端点、比较方向以及多重校正家族需共同核对。

数字从文字改成阿拉伯数字通常可以，但要记录。这不应被误判为新增结果。相反，保持相同数字却把“每增加一个预定单位”漏译，是严重意义变化。图注按实际定义区分置信区间、分位范围和其他计算范围，并准确翻译。

公式保护原生数学对象、变量、上下标与定义。正文改写不重新生成公式为图片或改变数学结构。若渲染的减号、单位或希腊字母存在差异，检查实际含义与可编辑性，不能只看文本抽取结果。

## 五、让两种语言都自然

先确定科学句子的主干：谁，在什么条件下，做了什么，观察到什么，以及它支持哪层判断。中文长句可以在英文拆分，英文名词串也可在中文展开。无需强求句数一一相同，但逻辑连接不能丢。

第一人称应与作者真实分析选择对应。有的英文用“We examined”更清楚，有的句子用研究对象作主语更自然。不要因中英对照而让所有段落同一开头，也不要为了“有人味”随意增添经历。

翻译完的英文必须作为独立论文段落阅读，检查代词是否有明确先行词、关系从句是否挂对对象、限定是否被放到错误分句。中文则检查量词、指代、连接词及过多嵌套是否造成歧义。两版都遵守作者的标点与句式偏好，但不得通过机械替换标点改变逻辑关系。

## 六、常见失败与修法

| 错误 | 为什么数值检查找不到 | 修法 |
|---|---|---|
| 观测记录译成独立分析单位 | 数字相同，对象改变 | 按实际计数单位逐段复核 |
| “伴随变化”译成“导致变化” | 没有数字变化 | 按原证据恢复关系类型 |
| 效应估计遗漏对应的单位或增量 | 数字仍相同 | 将尺度与估计放在同一句说明 |
| “合格端点均重叠”变“全部端点重叠” | 重叠数可能保留 | 保留资格条件与失败分母 |
| 引文从机制背景移到本研究结果 | 编号仍一致 | 以主张—引文映射重新定位 |
| 不同测定统称独立验证 | 名称被概括合并 | 保留各自构造、终点与测量对象 |
| 中文补了一句解释，英文未同步 | 局部语言润色被忽略 | 记录新增解释属于事实还是推论，两版同步审核 |
| 图号重排只改一版 | 正文内容本身没变 | 用统一图号映射同时更新所有组件 |

## 七、完整可复制prompt

### P09-A：建立术语与语义保护表

```text
请为以下双语稿建立一致性检查基础。
中文稿：{{中文}}
英文稿：{{英文}}
本轮基线与修改范围：{{基线}}
源结果、图表和引文表：{{来源}}

按科学功能配对段落，标明拆分或合并关系。
生成术语表，除中英名称外还记录定义、计数单位、证据身份和易混概念。
逐段列出必须保持的对象、条件、终点、效应尺度、方向、统计家族和引文归属。
发现两版已有冲突时先指出，不默认某一语言正确，不静默覆盖作者改动。
```

### P09-B：自然翻译或同步改写

```text
请把以下{{中文/英文}}段落转为{{英文/中文}}，并与已有对应稿同步。
源文：{{源文}}
现有对应稿：{{对应稿}}
术语与保护表：{{术语和语义}}
原始证据：{{结果与引用}}

保持科学含义、结论强度、分析对象、条件、终点和引用归属。
允许为自然表达拆句、合句或调整语序，不强求句数对应。
不能新增科研动机、实验、机制或推断，也不能丢失only、under、associated等限定的作用域。
输出成稿及重大结构变化的简短说明。歧义需标出并依据源材料判断，不用流畅句掩盖。
```

### P09-C：语义一致性专项审计

```text
请审计以下中英文是否表达同一科学内容。
双语文本：{{文本}}
原始数据定义及统计信息：{{定义}}
图表与文献支持表：{{对应表}}

除数字外，必须检查量词、单位、分母、纳入/合格条件、时间窗、终点、效应尺度、否定范围、因果强度与引用归属。
逐项输出差异、可能影响、来源依据和最小修正。
不要将术语统一处理成所有技术对象同义化。
没有问题的段落保持，不为句式整齐重写。完成后给出仍需作者判断的实际歧义。
```

### P09-D：整套双语交付同步

```text
请同步检查本轮双语交付文件。
文件清单：{{正文/Methods/图注/SI/表格/摘要}}
最终修改记录：{{变更}}
统一图号、引文和术语映射：{{映射}}
冻结基线及数据：{{基线}}

检查两版每项改动是否同步，尤其是范围条件、统计定义、补图引用和图注。
保留公式、表格、上下标与修订痕迹，核对接受修改后的文本与清稿一致。
输出逐文件通过项、差异及处理记录，并执行实际文档渲染检查。
不要仅凭文档能打开或数值token一致宣称双语与版式全部通过。
```

## 八、验收清单

- [ ] 主文、图注、Methods、SI和表注都已覆盖，未漏一类文件。
- [ ] 两版段落功能一致，拆合关系可追溯。
- [ ] 数值及其单位、分母、条件、终点和尺度相同。
- [ ] 关联、模型响应、机制和因果强度无漂移。
- [ ] 图号、引文、表格指向同一对象与主张。
- [ ] 术语稳定但句式自然，作者真实判断没有被删或编造。
- [ ] 公式、上下标、表格、修订痕迹及清稿已检查。
- [ ] 实际渲染无缺字、区间断裂或图表分页损坏。
