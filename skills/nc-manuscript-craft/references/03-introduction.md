# 03 Introduction：把研究放入已有知识，并自然引出贡献

> 应用范围：按本轮授权、请求语言和目标期刊配置执行。下文涉及双语、文件或图形交付的步骤，仅在任务需要时启用。教学示例不构成新项目事实。

Introduction的核心任务是建立问题引导过程。背景知识、文献和最后的贡献段都应服务同一个科学问题。以下步骤按稿件需要组合，不要求固定段数或起句。

## 一、输入与写作前判断

至少整理以下材料：

1. 本研究真正要回答的问题，面向哪些读者。
2. 最终主要发现及证据类型，不以拟开展实验代替已完成工作。
3. 与问题直接相关的既有方法、资源和最接近先例。
4. 每篇候选文献的实际支持范围和阅读层级。
5. 本研究相对先例的增量、未解决范围与可用资源。
6. 目标期刊、文章类型、预期引言篇幅和已有作者稿。

没有信息的地方标出缺口，先做可完成的结构工作。不要用“领域一直缺少”“首次系统揭示”等常见句填补未知。若作者给的是初步科学判断，先核对它是否被材料支持，再进入稿件。

## 二、先读范文的结构，再设计自己的路线

读范文时区分两个问题：作者说了什么，与作者为什么这样安排。此阶段关注后者，输出每段的职责、句间推进、段间承接以及引文角色。

对一段范文可记录：

| 字段 | 需要回答 |
|---|---|
| 段落目的 | 读者读完后新增理解是什么 |
| 首句动作 | 定义问题、提出矛盾、限定对象还是进入现有方法 |
| 支撑方式 | 常识概括、具体先例、比较、方法限制或数据事实 |
| 逻辑缺口 | 哪个问题尚未解决，依据来自哪里 |
| 下一段接口 | 哪个名词、对象或未回答问题被继续讨论 |
| 可迁移部分 | 组织方法，不能连同其证据强度直接搬来 |

不以句长均值、连接词频率或动词排名作为目标。这类统计至多描述所选语料，不能代表整个领域的规范。可以借鉴读者路径，不能借用别人有实验支撑的“验证”动词。

## 三、四项职责，灵活安排段落

### 1. 问题为什么值得研究

从具体科学或研究决策进入。应说明问题影响哪类理解、比较、测量或实验选择。不要连续几句停留在宏观重要性，更不要为了新颖刻意用问句开头。陈述句、问题句或一个具体矛盾都可成立，只要能引出本文问题。

较空的起点是“随着技术发展，这一领域受到越来越多关注”。更有用的写法要说明：现有观察留下了什么尚无法回答的研究选择。具体写法取决于本研究证据，不预先固定为同一个开篇模板。

### 2. 已有研究已经做到什么

按能力或研究路线组织文献，而不是逐篇排列作者名。每组工作说明它提供了什么能力、适用对象是什么、与本文问题的关系是什么。对直接先例给予准确归属，避免为了强调贡献而把已有工作描述成普遍不足。

方法与资源来自谁，当前研究实际改造或新增什么，应分开。使用成熟工具不妨碍论文有贡献，贡献可以落在新的研究对象、可复用定义、证据连接、受控比较或可靠应用上。

### 3. 当前还缺哪一步

缺口必须从前文能力自然推出，并能由本研究实际工作回应。不要写一个宏大缺口，最后仅提供局部工具。可把缺口拆为：已有研究可以完成X，但在特定研究任务中，Y仍未被定义、比较、测量或连接。这里的X/Y只是推理字段，不要求正文采用“不是X而是Y”式句型。

先检验缺口是否真实：直接先例是否已经做过，是否只是尚未在本体系/人群验证，是否只是作者未检索到。检索不足时，不把“未发现文献”写成“从未报道”。

### 4. 本研究实际完成什么

用清楚的动词给出研究对象和贡献。不用“本文首次提出一种新颖有效的方法”概括全部工作。可按贡献关系交代建了什么、比较了什么、获得了什么、使哪些任务可被复用，但避免写成逐节Results目录。

贡献段的每个承诺都应能在Results中兑现。计算推断、观察关联、模型扰动和外部测量保持各自身份。若研究主要是资源和方法支持，不借用机制论文的因果终点。

四项职责不等于四段。复杂研究可能需要分开两种方法路线，简短研究也可将现状与精确缺口合并。按论证负担决定段落，不按模板凑段数。

## 四、建立自己的段落卡

每张卡记录段落的唯一主要工作：

```text
段落ID：
本段让读者理解什么：
本段核心主张：
支持文献及各自角色：
上一段留下的具体问题：
本段回答了哪部分：
下一段还需回答什么：
不能超出的证据边界：
```

衔接优先靠继续同一研究对象或明确尚待回答的问题。不能只用however、therefore、moreover把彼此无关的事实连起来。读完每一段，检查“为什么下一段现在出现”。若答案只是“还有一组文献要介绍”，就需要重新组织。

## 五、常见失败与对应修法

| 失败形式 | 检查问题 | 修复操作 |
|---|---|---|
| 背景百科堆积 | 这些知识是否改变读者理解当前问题 | 删除不承担因果或论证作用的背景 |
| 逐篇文献流水账 | 文献间共同能力或分歧是什么 | 按问题/能力归组，保留关键先例 |
| 最后突然出现本研究 | 前文缺口是否正是本文解决对象 | 重写缺口与贡献接口，不只加therefore |
| 缺口过大、贡献过小 | 本文结果实际覆盖哪一步 | 缩小缺口，准确描述实际推进 |
| 过度贬低既有方法 | 是否忽略其适用条件或已达能力 | 正面归属已有贡献，再写具体不足 |
| 语言优美但缺事实 | 哪句具有明确对象和证据 | 补具体研究任务，删除价值口号 |
| 用结果数字填满引言 | 读者还未理解问题就看到详细结果 | 仅留贡献级概述，数据详述回Results |
| 同义替换破坏术语 | 同一技术对象是否被换成不同概念 | 依术语表统一，句式可变，定义不变 |

## 六、完整可复制prompt

### P03-A：范文Introduction结构拆解

```text
请分析以下已提供论文Introduction的写作结构，不要把任务变成内容摘要。
原文与来源：{{范文全文及来源}}
实际可读范围：{{阅读范围}}

逐段说明：核心目的、段内推理、段间关系、背景如何进入、现有能力怎样归组、缺口的依据以及研究工作如何被引出。
标出关键引文分别承担背景、原方法、直接先例或争议证据中的哪项作用。
最后提取可迁移的组织方法，并说明哪些措辞依赖该范文自己的实验或证据，不能直接搬到本研究。
不把句长、段数或动词频率变成我的稿件必须遵守的比例。
```

### P03-B：建立本研究引言路线

```text
请依据以下材料设计Introduction论证框架。
研究问题：{{问题}}
已有研究及已核实支持范围：{{文献证据}}
直接先例：{{最接近工作}}
本研究已完成内容与核心发现：{{贡献及证据}}
目标读者、期刊和篇幅：{{投稿语境}}
作者希望保留的判断与术语：{{作者偏好}}

先核对问题、现状、缺口和贡献是否匹配。
再逐段输出写作目的、核心主张、需要引用的证据类型、已有具体来源、上一段接口和下一段问题。
按论证需要决定段数，不机械使用四段，也不虚构新颖性或空白。
没有足够依据的缺口单列为待核实项，避免把未知写成“从未研究”。
```

### P03-C：依据确认框架写作或精修

```text
请按以下确认的引言路线完成{{初稿/精修}}。
框架：{{框架}}
现有稿件：{{稿件}}
可用文献与句子支持关系：{{引文表}}
已完成贡献及结论边界：{{证据合同}}

保持原有科学含义，不新增研究结论，不夸大既有方法的不足。
用具体问题、能力和缺口组织全文，避免背景百科、文献名单和价值口号。
让每段承接前段留下的问题，不只依赖转折词。
准确引用直接先例，区分原工具贡献与本研究实现。
输出完整引言及主要修改说明。若材料不足，标出该句需要的证据，不伪造引文。
```

### P03-D：反向检验引言承诺

```text
请审核以下Introduction与实际Results是否一致。
Introduction：{{引言}}
Results核心结论与图表：{{结果}}
引用证据：{{来源}}

逐项检查：研究问题是否具体、直接先例是否公平、缺口是否真实、贡献是否全部兑现、术语与证据强度是否一致、段间跳跃和重复是否存在。
特别指出“未测量却写成测量”“关联写因果”“未找到文献写成未有研究”等漂移。
先给最小必要修正，再提供清稿。不要为语言华丽重写无问题段落。
```

## 七、验收清单

- [ ] 每段都有清楚工作，整体引向同一个研究问题。
- [ ] 已有能力和直接先例被公平说明，原工具与当前研究贡献有归属。
- [ ] 缺口有来源，不比本研究实际回答范围大。
- [ ] 文献支持被引主张，而非只与关键词相近。
- [ ] 贡献段在Results中逐项可兑现，没有实验、因果或临床用途越界。
- [ ] 衔接靠具体对象与问题，不靠连续过渡词或固定“We next”。
- [ ] 中英文术语、引文与结论强度一致。
