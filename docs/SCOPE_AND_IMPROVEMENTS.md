# Scope and writing decisions

NC Manuscript Craft supports complete drafting from study materials and targeted revision of mature manuscripts. The requested outcome determines how much work to do. Sufficient evidence supports a finished draft, while a local information gap affects only the sections that depend on it.

## What the v1.2.1 candidate adds

The full drafting workflow still accepts project files, a rough author framework and spoken notes. New guidance primarily improves the choice of information and the relationship between sections: specific research choices in abstracts, research capabilities before software lists, and explanatory questions before repetitive module announcements in Discussion.

There is no universal requirement to use question sentences, match or avoid a particular paragraph count, or place every explanation plot in the main text. Authors' choices remain evidence-bound. Figure decisions consider the information a panel adds to the central contribution while keeping its actual statistical and biological meaning clear.

The candidate incorporates voice refinements that had already been used locally after v1.1.0, including contribution-forward wording and fewer artificial binary contrasts or rhetorical triads. These are preferences applied where useful, not quotas or detector-evasion techniques.

## What v1.1.0 added

| Situation | Writing decision |
|---|---|
| External advice conflicts with the draft | Locate the reviewed version, inspect the current source and rendered page, then adopt, adapt or retain the wording based on the finding |
| Discussion describes an analysis but leaves its result unexplained | Connect the actual observation to its interpretation and the next discriminating question |
| A resource's value reads as a feature list | Explain how a stable research object moves through useful analytical tasks |
| Two computational versions serve different analyses | Define each version's role and comparison conditions using the recorded workflow |
| Methods disagree with summaries | Trace the executed code, configuration and output, including selection, thresholds, ties and aggregation |
| A figure mixes schematics and statistical panels | Assign the correct population, visual encoding and inferential description to each relevant panel |
| Supplementary sections seem repetitive | Move unique definitions and reproducibility details to their appropriate destination before removing duplicate prose |
| Reading files need to become a submission package | Map final files to the current journal's article type, submission stage and upload categories |
| A repository introduction reads like an audit | Lead with writing tasks, use and outputs, placing conditions beside the actions they affect |

These decisions refine the original whole-paper workflow. They apply when the corresponding problem occurs, without imposing a universal paragraph count, threshold method or journal layout.

## Continuing capabilities

The workflow covers argument, sections, methods, citations, figures, supplementary text and requested language synchronization. Stable evidence identities connect the components. Saved source versions and author decisions allow long tasks to resume and reopen only the passages affected by new evidence.

The [standalone prompt](../FINAL_PROMPT_ZH.md) contains the complete workflow in one file. The installed skill uses short routing instructions and loads the relevant modules as needed. Optional blank templates support substantial projects, while local edits can proceed directly.

## Research and delivery context

Authors supply the study evidence and decisions. The assistant develops prose, identifies unresolved factual questions and reports the checks actually performed. New experiments, new analyses, correspondence and publication actions follow their own explicit task scope.

Exact journal requirements are checked for the current article type and stage. File generation, document rendering and scientific review have separate verification records. The public package contains generic instructions and synthetic teaching fixtures. Its research examples serve instruction, not another manuscript's evidence.
