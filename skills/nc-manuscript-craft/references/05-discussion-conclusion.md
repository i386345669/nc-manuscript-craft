# 05 Discussion与结尾：推进对研究发现的理解

Discussion的工作是解释本研究改变了什么理解、为什么可能出现这些结果，以及与已有研究怎样相接。需要区分关键解释时，再提出具体可检验的问题。它不应成为Results复述、文献名单或逐条自我辩护。先组织解释与证据关系，再形成正文，可减少推论跳跃。材料足够且作者要求成稿时，完成正文，不停在提纲阶段。

## 一、输入先围绕证据组织

对每项值得讨论的结果填写一张解释卡：

| 项目 | 记录内容 |
|---|---|
| 实际观察 | 对象、条件、终点、方向、必要量化及图表位置 |
| 证据身份 | 实验测量、观察关联、模型推断、计算扰动或预测归因 |
| 支持的观点 | 这一结果实际回答研究问题的哪一部分 |
| 候选解释 | 与哪些观察相容，哪些环节尚未检验 |
| 比较文献 | 具体研究对象、方法、方向及可比/不可比条件 |
| 其他解释 | 同样能产生结果的合理替代解释 |
| 后续检验 | 为区分解释，需要测量什么、比较什么、在什么对象中检验 |

只纳入对主要论证有作用的卡。不是每个显著P值都需要一段机制解释，也不是每张图都要在Discussion重述一次。先决定本研究最值得解释的推进，再组织段落。

## 二、从总体贡献到具体解释

开头用少量篇幅解释主要贡献的含义，而非照摘要重新列所有结果。资源型论文可以说明研究对象如何变得可定位、可比较或可复用。方法型论文说明研究任务现在能够怎样完成。机制型论文才以已被实验支持的机制推进为中心。

关键解释段应包含承担推论的实际观察。若一段只说明分析怎样定义，或某种读出“可以怎样考察”，应回到已有结果，说明实际发生了什么、它对当前问题增加了什么认识。定义仍在需要的位置保留，观察与解释可按阅读需要分句或交织，不套固定段落顺序。

后文围绕研究问题展开解释：结果增加了什么认识，与已有知识在哪些方面相符或不同，还有哪些解释值得区分，以及怎样继续研究。根据本研究实际证据选择需要深入的内容，段落数量和顺序随论证责任安排。

教学情境：观察性队列、计算模型与实验测量同时用于回答一个问题，但各自定义了不同终点。三者可构成互补证据，不能仅因方向相似便称为同一机制的独立验证。先核清是否测量同一对象，再决定如何连接。

### 以解释职责判断结构，不按段数判断

Discussion与Results段数相同，本身不能证明讨论在逐项复述。先看每段增加了什么解释，以及是否合并了不同结果的共同意义。按结果顺序展开可以成立，跨结果按主题组织也可以成立。保留已充分连接观察、文献和测量选择的段落，不为打破表面对应而强制重排或合并。

若多个段落连续以“第一个案例”“另一项应用”或模块名称开头，先检查它们各自讨论的问题。可将入口改为一个解释命题，再引入相应实例，例如某项发现为何出现、不同来源的证据分别回答了问题的哪个方面。这是对确有阅读阻力的入口作局部处理，不要求所有段落使用同一种命题句。

## 三、机制解释按证据分层

推荐在规划阶段明确三层，正文则自然表达，不必反复贴标签：

- **已观察到的结果**：直接报告实际观察或计算所得内容，并明确它的对象与来源。
- **证据支持的解释**：指出哪些结果或已核实文献支持解释，同时交代关键条件。
- **待检验假说**：说明为何合理、还缺哪一项鉴别证据，使用与不确定性相称的限定。

“may”“suggest”“demonstrate”不是装饰性的同义词。不能一律换成弱词使全文畏缩，也不能一律换成强词增强气势。对已明确完成的操作、观察或测量，可以直述。对解释链上尚未检验的环节，限定应落在那个环节，而非给整段加一层泛泛谨慎。

示例只说明边界：

> 教学句式：Within the specified simulation, changing [input] altered [output].
>
> 另一层待证实的主张：Changing [input] produces a real-world benefit.

这些是带待填变量的合成句式。第二句改变了适用对象和结果层级，需要由相应证据支持。

## 四、文献比较需要回答“如何可比”

先确定需要比较的文献类型，再检索并核实具体来源。常见比较维度包括对象、人群、条件、测量层级、模型假设、效应方向和研究终点。讨论不能只说“与某团队一致”，应说明其结果支持本文哪一层解释，以及本文新增或不同之处。

在另一研究体系完成的机制实验，可以支持候选解释，但不能替代当前体系的验证。相反结果也不必自动判为冲突，先检查测量是否同一层、是否存在条件差异。关于原创性和已有研究范围的判断，同样依据实际检索与文献内容。

文章自身的原创数值来自本研究图表与源结果。外部文献解释背景与机制，不充当“本研究效应值”的来源。

## 五、在解释中说明实际条件与后续问题

当某项条件影响结果的理解，在相应论点交代研究的实际范围、当前证据支持的内容及需要进一步区分的问题。共同背景可集中说明，方法与实现细节进入对应章节。

后续研究建议应有明确的鉴别作用：先说明要区分哪些解释，再据此选择测量、比较或研究设计。保留最有针对性的问题，允许段落在解释完成处自然结束。

对样本、设计或测量尚不充分之处，具体说明它影响的判断。按已有证据描述不确定性，新的数据或方法可能带来的变化则作为待检验问题。

## 六、结尾与独立Conclusion

是否单设Conclusion由文章类型和作者稿件决定，不能为了套模板额外添加。Discussion末段通常可完成收束：本研究支持的主要增量、可用方式和最具体的下一问题。

最后一项应用的结果解释与全文收束承担不同任务。若一段从局部表现转入整篇研究的长期用途，且两部分都需要展开，可另起一个简短结语段。段落边界由职责决定，不设固定段数。资源或方法型研究可以在此说明已有工作如何成为后续研究的起点，以及新证据出现时能够重新考察什么，具体操作步骤留在资源介绍或Methods。

若结尾首句只是重复开头的“共同起点”或一般价值，可删除该句，让已有的具体使用动作或研究问题承担收束；若该句引入新的层级或职责，则保留。不要为了更像结论而再加一句同义赞语。

结尾不要再列一次全部Results，也不制造“开启新时代”的远景。只在证据支持时给直接研究意义。若是资源论文，可回到它使什么研究对象可被查询和复用。若是发现论文，可回到它改变了哪一认识。承诺未来用途与已经实现的用途分别写。

## 七、完整可复制prompt

### P05-A：从关键结果提取讨论路线

```text
我正在撰写Discussion。请根据以下材料先设计论证，不直接堆文献或重复Results。
研究问题：{{问题}}
核心贡献：{{贡献}}
关键结果卡，含对象/条件/图表/方向/证据类型：{{结果卡}}
已核实文献及支持范围：{{文献}}
作者希望讨论的判断：{{作者判断}}

逐项说明结果支持什么观点、可能解释、可比较文献维度、替代解释及当前限制。
把需要后续证据的解释明确标出，不添加数据或机制。
随后给出段落路线，说明每段的解释任务与实际连接关系。本轮要求成稿且材料足够时，继续完成Discussion正文。
按论证需要安排，不要求每段重复同一套五步结构。
```

### P05-B：机制与文献比较专项

```text
请审查以下Discussion中的机制解释和文献比较。
草稿：{{草稿}}
本研究实际证据：{{数据与图表}}
文献原文或已核实片段：{{来源}}

区分直接观察、证据支持的解释和待验证假说。
每个机制说明对应哪些观察、引用支持哪一环以及哪个环节仍未检验。
比较具体对象、条件、测量层级和终点，不能只写“与已有研究一致”。
核对关联与因果、不同研究体系的适用条件，以及本研究数值的真实来源，并据此完成必要修订。
未知的新颖性或未检索领域保持未知，不推断“首次”或“尚无报道”。
```

### P05-C：说明实际条件并形成正向解释

```text
请依据实际证据，用正向、直接的叙述说明以下研究条件及其解释作用。
文本：{{文本}}
实际输入、设计和测量范围：{{范围}}
必要条件与已完成检查：{{条件}}

在影响理解的相应论点说明实际研究范围、已支持的判断和最相关的后续比较。
依据记录保留观察、设计与不确定性，按其解释作用安排位置。
将重复自辩改为准确的对象和条件说明，详细实现诊断放入Methods/SI。
输出修订稿和“保留/合并/移位/删除—理由—证据是否仍在”的表。
```

### P05-D：形成Discussion成稿与结尾

```text
请依据已确认路线完成Discussion。
路线与贡献层级：{{路线}}
已核实结果及引用：{{证据}}
需要保持的作者判断和术语：{{作者声音}}
具体局限与可检验问题：{{边界}}
篇幅与是否单设Conclusion：{{篇幅配置}}

用结果对科学问题的回答组织段落，按需要连接实际发现、解释、相关知识与后续研究。
不逐项重述Results，不将不同外部测量写成同一验证链，不增加新机制、首创或未测收益。
长短句和段落详略由论证内容决定，不强行统一或随机打散。
结尾回到已支持贡献和具体下一问题，避免笼统宏大展望。
输出成稿和少量关键取舍说明，并检查所有引用与其主张匹配。
```

## 八、验收清单

- [ ] 开头解释贡献，不复述全部结果。
- [ ] 机制各环节与观察、文献或理论支持对应。
- [ ] 相关、模型扰动、实验和预测归因身份保持。
- [ ] 文献比较说明对象与条件，未借用他人验证替本研究背书。
- [ ] 局限具体到推论与测量，未猜误差方向或收益。
- [ ] 不反复自辩，必要边界仍在读者可见位置。
- [ ] 结尾既没有全盘保留套话，也没有新增夸大意义。
- [ ] 是否独立Conclusion符合实际稿件结构。
