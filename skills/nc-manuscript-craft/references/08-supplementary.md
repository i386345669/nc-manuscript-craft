# 08｜补充材料：与主文同步的科学写作

补充材料承载可复现细节、完整结果和读图信息，采用与主文一致的科学与语言标准。工作日志和编辑记录按各自用途另存。本模块用于现有SI定向修改，也可据完整来源构建SI。主文以何种权限可改、补充材料以何种权限可改应分别登记，不能因SI获授权就重写主文。

## 输入与覆盖

从零组织SI时，依据项目结果、图表、方法、参数与主文需要建立补充内容。修改已有SI时，以当前SI或目标部分及必要上下文为必需基线，再核对相关主文、图注、表格、引用和来源。建立本轮覆盖索引，记录各组件与正文入口，并据实际读取范围完成交付。

若作者提供带红字/删除线副本，先提取已生效差异、批注和格式语义。红字改写、红字加删除线删除，未标位置按本轮权限保护。作者已删内容不能换到附录重新出现。保留原件，修改另存。涉及双语版本时同步。

## 组织原则

按实际内容分Supplementary Figures、Tables、Methods或期刊要求的其他部分。标题说明对象和任务，正文直接进入方法、结果和定义。不要在每节开头解释“本节不能证实什么”。读者需要知道做了什么、怎样做、看到了什么以及怎样读图。

每段先识别功能：

| 功能 | 处理 |
|---|---|
| 参数、资格、分母、变换、区间、统计家族 | 保留并使定义清楚，必要时表格化 |
| 补充结果与完整比较 | 直接报告实际方向、量级和不确定性 |
| 图表编码及误差定义 | 放图注或表注对应位置，避免读者跨多处找含义 |
| 为预判审稿质疑重复说“不证明/不认证/不能泛化” | 删除修辞层，把必要身份融入量或设计名称 |
| 旧回执、debug历史、修稿原因、已修正错误 | 移至audit/溯源记录，SI只保当前复现信息 |
| 正文已有定义且SI没有新用途 | 逐项确认信息已覆盖后合并或交叉引用，避免重复长段 |
| 操作本身的否定，如未重新拟合 | 按实际科学意义保留或改成固定权重的肯定定义 |

不能靠机械禁词删除所有“未”“不”。“未达到阈值”“未测得有限值”可能是结果或规则。也不能把“不显著”换成“趋势明显”来制造阳性叙述。

审阅称为“重复”的段落也可能包含唯一公式、资格条件或来源。删除前将必要事实与拟保留位置逐项对照。完全重复可直接删；混有唯一信息时，先迁入功能正确的小节并保留引用，再删除错位段落。最后确认必要定义仍完整且没有重复回流。这个动作不允许恢复作者明确禁止保留的内容。

方法缺口优先从产生现有结果的真实执行版本核定，而不是采用常见做法补写。对阈值、派生分类、合格集合和重复汇总，检查实际代码或实验记录中的完整规则，并与保存结果连接。完整判据放在Methods，图注给必要简述和准确入口。执行来源的核查尺度见[模块20](20-evidence-and-state.md)。

## 从范例学习而非复制模板

先读提供范例的完整图注、表和方法，再记录每部分目的、信息密度及省略的理由。范例图中已自明的流程可以用短图注，实验/模拟并列的图则必须写单位、n、线条身份和检验。完整不要求每条图注等长。

范例的页数、图数和表数只适用于它的证据负担，不构成新稿配额。发表过的文件也可能有交叉引用或分页问题，仍应独立检查。期刊正式格式要求另行查核，不能从某篇范例没有Supplementary Methods推断当前稿也不能有。

## 用正面定义表达必要条件

重复设计直接说明实际独立单位和实施方式，后文沿用该定义。区间或误差范围按实际估计过程命名，完整计算规则放在对应方法。不同数据产品分别记录输入、处理和用途，让读者清楚每个结果的来源和含义。

将这些信息放在首次理解结果所需的位置，后文保持术语一致。共同条件可集中说明，独有条件随相应结果交代，完整观察和不确定性据实保留。

## 主文、SI与独立表册同步

正文简化的工程参数必须在SI保留精确值和来源，改写范围只限明确授权值。效应量、阈值、统计结果不能顺手round。SI公式保留原生结构及上下标，独立表册与SI内表在数字、题注和脚注上一致。

主文与SI若独立编号参考文献，应分别维护，不把总RIS库项数当正文引用数。补图移动或拆平后，更新中英正文、图注、表注、图源MD和导航，反向检查所有新编号有去处。术语、指标定义、比较组和统计名称保持一致。

少用非必要分号，但技术字段分隔及复杂分组可保留。改变句界后再查引文和条件覆盖，避免多一处句号造成后半句失去范围。

完整Figure核对册与最终尺寸SI排版分别承担整图核对和实际阅读任务，具体处理见[模块07](07-figures-legends.md)。任何方案都不能以未组装的单panel分页版充当完整补图阅读版。独立面板仍保留编辑用途。SI文字文件、图合集及含图整合版分别验证内容范围，不能仅凭相近文件名认为它们可互相替代。

## 整合为投稿SI时

仅在请求整合文件或准备投稿版时启用。按当前期刊要求组合图、图注、表、方法和参考文献，并记录每个组件的来源与目标位置。若文字文件开头已有全部图注，合并图与图注后应从真实正文边界接入，不能把旧图注再附加一次。

边界依据实际标题或文档结构定位，区分正文标题、目录条目和文中提及，不能以第一次搜索命中切页。跨页边界不清时先查相邻页内容。验证每个所需组件完整且只出现应有次数，独立编号参考文献保持身份及正确位置。图注放在安全留白处或适当的后续页，不以压缩图中文字来强行容纳。

正文、图页和单独图注已通过检查，也仍需查看最终合成PDF的字形、页码和拼接处。公式内容正确不保证输出字体覆盖所有符号。对缺字、上下标或字体回退问题做定向修复，再查受影响页。不要因重排而删去统计条件、完整数据或必要参考文献。

## 验收与停止条件

要求全部索引项有对应输出，作者删除请求落实，未授权内容未改，数字/公式/表结构/来源保护通过，要求双语时主张和条件对齐，图表引用正确。真正渲染全部输出页面，检查近空页、表头、跨页表、裁切、字形、公式和图号。

检测到问题则定点修复并重查受影响内容，无新问题后停止。不可因“还想更像人写的”反复全稿改写，也不提供未测得的AI检测改善百分比。无法核定的科学问题单列并完成其余工作，不以旧已解决问题反复阻塞。

## P08-A｜SI完整覆盖与结构诊断

请完整读取本轮请求语言的补充材料、图表、方法、作者副本及相关主文，先列覆盖索引。逐段标记是复现定义、补充结果、读图说明、重复内容还是审计/防御叙述。删除重复段前核对其中是否仍含唯一公式、条件或来源，先迁入正确位置再去重。保留必要数据、统计与真实结果，把元叙述从论文中剥离。作者明确禁止恢复的信息不得转移重现，未授权主文不改。输出结构问题、最小修复、主文/表册/图注同步点及实际未读范围。输入与权限：【粘贴】。

## P08-B｜SI的正向叙述与准确表达

请按已确认覆盖索引修订SI，直接交代对象、操作、观察和读图定义。以准确的设计、对象和指标定义表达适用范围，使研究操作和实际结果清楚可读。保留操作性否定、真实阴性结果、数值、资格、分母、区间性质、统计家族、公式与来源。工程参数若获准正文近似，SI仍保精确值。少用分号，不机械替换技术分隔符。按请求语言输出完整改稿及原文—改文—理由—语义核验表。双语任务同步两版。材料：【粘贴】。

## P08-C｜SI与主文、补图、表册的终检

请独立比对修改前后SI与主文、独立表册、完整补图合集。检查遗漏、越权改动、已删内容回流、图号、引用、人群、测量身份、统计定义、双语条件和精确参数。检查接受真实修订得到清稿、拒绝修订回到指定基线，原生公式保持。逐页看渲染结果，验证各版按用途与当前分页要求保留全部Figure和panel，完整核对版未另指定时一Figure一页。整合SI另查结构边界、组件重复与缺失。区分核查通过、已修复、未能核查，不写笼统全通过。无新实质问题即停止。输入：【粘贴】。

## P08-D｜整合可读的投稿SI

请按已核验的当前期刊要求，将最终补图、图注、表格、方法和参考文献整合为所需SI文件。先辨认各输入实际包含什么，依据真实标题或结构确定拼接边界，不把目录或正文提及当作起点。保留全部panel、统计定义、原生来源和独立参考编号，验证每个组件完整且没有重复附加。按最终尺寸排版，需要且允许时使用continued图页，并保留图号/panel/页码映射。逐页查看合成结果的图注位置、字体符号、公式、表头和页码。输出整合文件、简短组件映射及未能核查项，保留原有可编辑材料。输入、目标格式与用途：【粘贴】。
