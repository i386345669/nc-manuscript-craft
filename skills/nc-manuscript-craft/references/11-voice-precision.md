# 11 作者声音、去防御与精确表达

> 应用范围：按本轮授权、请求语言和目标期刊配置执行。下文涉及双语、文件或图形交付的步骤，仅在任务需要时启用。教学示例不构成新项目事实。

## 目标与判断顺序

先检查句子承担的科学工作，再处理语言。能够清楚说出“谁、在什么条件下、得到什么、据此能说什么”的句子，通常比添加高级词更有效。自然声音来自作者的判断和内容的轻重，不来自固定的句式配方。

判断顺序是：事实与条件正确 → 段落功能明确 → 信息关系可读 → 节奏与用词自然。漂亮但改变条件的句子必须退回。已经清楚准确的句子可以保留。

## 1. 去防御的对象是什么

防御性修辞包括：重复声明某分析不是什么，预先回答并未提出的审稿质疑，反复强调内部审计合格，用自我贬低覆盖贡献，或让每个发现后面跟随一段同样的免责句。

以下内容有科学作用，不能按关键词删除：观察性设计、模型内扰动身份、实际测量量、样本资格、关键相反结果、替代解释、分母、统计家族、数据缺失状态。不是看到“未”“仅”“可能”就删。

| 原表达问题 | 可用改法 | 要检查什么 |
|---|---|---|
| “这不是直接通量验证，不能据此说明……”在多处重复 | 在比较入口明确“细胞内代谢物丰度对比”，在相应方法定义估计量 | 是否仍能辨认测量对象和支持范围 |
| “我们通过审计、冻结和核验确保……”成为Results中心 | 以得到的对象、比较或发现开头，把运行清单转到来源记录 | 是否把真实方法或失败分母一并删掉 |
| “这些发现仅仅是初步线索”笼统压低全部结果 | 具体说明该结果在当前人群/设计中的含义 | 不把谨慎换成无根据的强结论 |
| 每个图注都说“不证明因果、不是独立验证” | 直接写“回顾性关联”“模型删除”“同一患者重复计算”等准确身份 | 实际读图信息是否完整 |
| 需要解释的阴性或冲突结果被归为“防御” | 保留实际数值和含义，缩短重复议论 | 是否改变读者对关键结论的判断 |

编辑决定可用KEEP、TIGHTEN、REFRAME、RELOCATE、CUT、QUERY。CUT只删无信息修辞，不能悄悄删除事实命题。作者明确撤回的文字不应以“保护范围”为理由移到别处复活，可以利用既有准确术语维持含义。

## 2. 去模板化的具体动作

**重复收束。** 若末句只是把上一句换成“这些结果共同说明”，删除通常有效。但末句若说明为何固定一个读出或为何进入下一测定，它承担论证功能，应保留或压缩。仅按字数选择更短版本，可能损失这种桥接。

**空泛开场。** “近年来受到广泛关注”只有在确实引出一个具体变化时有用。优先从当前科学决策切入，例如现有观察尚不能决定下一步应比较什么或测量什么。设问可用，但不是每篇引言必须用问号。

**宏大意义。** 把“有重要意义”“开辟新范式”换成实际改变：可检索哪个对象、能执行哪种比较、如何选择测量、能复用什么分析。若确有广泛贡献，不必人为缩小，只要明确其依据和作用对象。

**内部术语。** 集合键、门限简称和反复出现的管理状态，可以改为读者能够直接理解的人群、测量量、变化幅度或实际规则。用于复现的技术标识保留在相应方法和数据中。某个词若承担真实的方法限定，定义后继续准确使用，不按词表机械删除，也不因改名省去阈值、分母或约束。

**假对比。** 删除没有实质对照的“not merely X but Y”。保留真实的测量差异、固定读出与替代解释，改成准确的正面定义。

**机械三联。** 三个真实对象可以并列。三项抽象同义形容词或为凑节奏重复同一贡献，可以缩短。不要把“三个”本身当错误。

**章际密度。** 摘要精练，引言展开问题，Results给发现和必要研究选择，Discussion展开解释与比较，Methods精确定义。不同章节不需同样句长、段长或结尾。

## 3. we、被动语态与主语选择

we适合表达作者真实的设计选择。教学句式如“We applied the same eligibility rule to both groups.” 研究对象也可作入口，如“Both groups were assessed using the same rule.” 两种形式可以共存。只有当前研究实际使用了该规则时，才能将示例用于稿件。

开头词频可以帮助定位重复，但不是编辑配额。不得规定“每隔固定段数换一个主语”或“we全部改被动”。英文被动语态在行动者不重要时也自然。

改变主语后必须检查动作仍合理。训练数据“用于拟合”比folds“保留预处理”更明确。不要为形式变化制造拟人化或无主句。

## 4. 长短句与逻辑关系

先找长句中几个不同任务：对象定义、设计、结果、解释、引文。若分别成立，可拆开。若第二部分依赖前句限定，优先明确指代或保留连接。

拆句时检查：否定作用域、only/where/when、each/all/some、before/after、条件分支、因果和比较是否变化。合句时检查不同测量、两个人群或两项统计是否被误并为一个对象。

不按30词或某个平均句长自动截断。篇幅是诊断线索，信息关系才是编辑依据。短句堆叠同样会让研究叙事碎裂。

## 5. 少用分号的实际规则

当本轮采用“尽量少分号”的写作偏好时，同时检查中文“；”和英文“;”。逐处处理，不作全文字符替换。此偏好不是期刊的普遍硬性规定。

1. 两个完整独立陈述：改为句号。英文后句首词适当大写，但不要改变q、n或其他专名/变量的大小写。
2. 有真实并列、转折或条件关系：用and、whereas、while或中文明确关系词。不要仅用逗号连接两个英文独立句。
3. 括号内统计与图号：可改逗号，保持每个区间、事件数、P/q与对应结果的归属。
4. 表格名词短语：可用逗号、with或简短说明。不要拆出无意义独立句，如“同一冻结分数与C。”
5. 内含逗号的复杂组别：保留必要分号，避免成员边界变模糊。
6. 导出的类别字段，如`female;male`：这是字段序列，保留分隔符，除非任务明确改显示格式。
7. 联合引文：若原一句末的引用同时支持分号前后两部分，拆句会改变视觉上的支持范围。可改连接词，或在核实后重新分配引用。不能只验引用数字数量相等。

教学合成例：一句话分别介绍方法A与方法B，句末的一组引文共同支持两部分。拆成两句后，不能让引文看似只支持后一句。可以在核实来源后重新分配引文，也可以用表达真实关系的连接词保留一个完整被引句。分号处理服从引用关系。

## 6. 真实研究痕迹

可写的是已经记录的设计理由：为何比较同一患者网络、为何合并共享变化、为何固定权重、为何排除直接靶项。它们说明研究者在解决什么问题。

需要额外记录才能写的是时间性经历：“最初失败”“曾预期相反”“意外发现”“前期工作表明”。不能把一次后续生化注释纠正，改写成事先假设被结果推翻。最终程序里的一个选择并不能证明作者过去试过其他方案。

没有过程证据时，保留当前设计目的即可。无需为了自然感增加一段科研故事。

## 7. 精确限定与具体局限

限定词对应证据，不对应文风。associated with不能轮换成led to。suggest和prove不是风格同义词。也不要机械弱化已经充分支持的结果。

局限要说明实际输入/设计缺什么、这影响哪个判断、需要哪种可区分的测量。教学情境：输入只在一个时间点测量，便不能直接描述个体随后变化。这项边界本身不能确定偏差方向，也不能保证增加纵向测量一定提高预测表现。

同样，不能从队列名称推断其人群构成，也不能从少量文献中未见报道推断某领域从未研究。它们都需要相应证据。

## 8. AI风格诊断的输出边界

报告具体、可检验的问题，如重复开头、空泛形容、条件丢失或引用漂移。不要把这些换算成“AI生成率下降”“不会触发检测”或“编辑大概率不会询问”。保留实际AI使用说明。任何局部对照都应注明材料、执行条件与评阅范围，不能直接升级为工具普遍排名。

## 9. 面向读者的介绍

README、工具介绍和交付说明也采用清楚、具体的表达。先说明读者可以完成什么工作，再给直接使用方式和按需深入的入口。将能力范围、工具条件、许可和实际评估放在各自相关位置，压缩反复否定与自证。功能陈述仍应对应已经具备的能力，影响理解的条件随相关用途说明，详细执行规则保留在指南中。

## 可复制 prompts

### P11-A 去防御但保留科学含义

```text
请在当前授权范围内审查并修订防御性写作。
先区分：重复自辩/预演审稿质疑/工程过程叙述，与真正影响结论的设计事实、相反结果、范围条件和替代解释。
对候选句作KEEP、TIGHTEN、REFRAME、RELOCATE、CUT或QUERY判断。
把重复否定改为准确对象与操作定义，保留贡献，不能让结论比证据更强。
不要按“仅、未、可能、不是”等词机械删除，也不要恢复作者已经明确删除的修辞。
输出修改稿和必要的原文—改文—理由，说明哪些条件得到保留。成熟且合适的段落不改。
【稿件/范围/作者决定/证据】
```

### P11-B 去模板化与作者声音

```text
请对以下成熟稿做局部清晰度与节奏修订。
检查重复收束、空泛开场、假对比、无信息排比和堆叠长句。每项回到段落任务判断。
保留真正说明研究选择和下一步理由的we与过渡句。主语、长短句和图注入口按内容调整，不设改写比例。
术语、统计定义、数字、条件、引用和结论力度保持一致。不得虚构试错、预期、惊讶或作者前期成果。
不追求检测器分数，不故意制造口语化、含混或错误。只修复有明确收益的地方。
【当前文本与风格样本】
```

### P11-C 分号专项微调

```text
请尽量减少以下中英文文本的分号，保持科学内容和引用归属。
逐处选择句号、逗号、明确连接词或必要保留。英文避免comma splice和残句，保持变量/专名大小写。
拆句后检查联合引文是否仍支持原来的全部命题，统计量与人群是否仍正确配对。
技术字段与复杂组别允许保留分号，不追求机械清零。
同步当前任务要求的中英稿、图注、SI及修订版，只报告实际改动与必要保留理由。
【文本或文件】
```

### P11-D 三步润色与反向核查

```text
请分三步处理本段，但只在最终输出中保留必要说明：
第一步修正语法、拼写和搭配，标出原意不清之处。
第二步提高学术清晰度和简洁度，不改变技术含义或结论力度。
第三步对照原文检查逻辑、重复、方法—观察—解释关系，以及所有量词、条件、否定和引文作用。
无法据来源解决的科学问题列为待确认，不用更流畅的文字掩盖。
输出最终文本与重要修改理由。无需修改的句子保持。
【原文/证据/授权范围】
```
