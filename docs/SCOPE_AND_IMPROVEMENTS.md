# Scope and completeness

This release supports two different depths of work: completing a manuscript from supplied study materials, and preserving a mature draft while making targeted changes. A request for a full paper should not end at an outline when the evidence is sufficient.

## Execution improvements

| Area | Implemented behavior |
|---|---|
| Whole-paper completion | Required, conditional and unrequested components are distinguished. The workflow continues through actual sections and checks |
| Material readiness | Ready evidence, local gaps, conflicting sources and planned-only research receive different outputs |
| Study type | Observational, experimental, prediction, methods, resource, qualitative and evidence-synthesis tasks preserve their own evidence units |
| Evidence mapping | Stable result/source identities connect Methods, Results, figures, tables, legends, citations and supplementary text |
| Continuation | Large tasks can save actual drafts, source versions, decisions, queries and next actions. Source changes reopen dependent components only |
| Single-document portability | The standalone prompt contains the full workflow and section instructions without requiring the installed skill |
| Language scope | Single-language requests remain single-language. Bilingual synchronization is applied when requested |
| Tool limitations | Text, actual files, rendering and independent review have separate verification status |
| Behavioral evaluation | Complete drafting, missing results and source-update continuation have concrete synthetic fixtures |

These are capability and scope improvements. They do not imply that all earlier writing outputs failed. More blanket style prohibitions are not the objective.

## What remains the author's responsibility

The workflow cannot make absent experiments real, resolve scientific ambiguity without evidence, or guarantee publication. Authors must verify the final research meaning, underlying results, required declarations and applicable policies. A polished file with unresolved evidence is a stage draft, not a certified submission.

New analyses, external uploads, public data sharing, correspondence and journal submission are not implied by a writing request. They require their own current authorization.

## Public package boundary

The repository contains generic instructions, optional blank templates, synthetic fixtures and public attribution. It does not contain the private development history, source manuscripts, research numbers or internal decision logs used to inform the workflow. Examples are teaching material, never evidence for another project.

The skill name reflects a style preference. There is no fixed journal word count, figure count, reference quota or project-specific study identity. Check current official requirements when exact submission rules matter.
